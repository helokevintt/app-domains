# app-domains

各应用官方域名清单。

## 收录规则

- 只收录官网、官方 FAQ、官方文档或 DNS 记录可以核实的域名。
- 每个应用一个文件，放在 `apps/` 目录下，文件名用应用名小写。
- 钓鱼、仿冒域名不算官方域名，单独列在各应用文件末尾的“不是官方”一节，只作提醒。
- 每条清单注明核实日期和来源。
