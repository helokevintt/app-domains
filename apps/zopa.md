# Zopa Bank 官方域名

核实日期：2026-11-26
来源：FCA 官网登记信息、Zopa 官网、DNS 子域名扫描（2026-11-16，277 个子域名）

Zopa Bank Limited（FCA 注册号 800542）是英国持牌数字银行。Zopa 没有公布过完整域名清单，以下是能核实的。

## 官网与主站

| 域名 | 用途 |
| --- | --- |
| zopa.com | 官网主站，FCA 登记的官网；域名注册于 2001-05-05，持有人 Zopa Bank Limited |
| zopa.co.uk | 跳转到 zopa.com |

## 邮件域名

| 域名 | 用途 |
| --- | --- |
| @zopa.com | 官方邮件，包括客服 contactus@zopa.com、媒体 pr@zopa.com |
| mail.zopa.com | 邮件发送子域名（Salesforce Marketing Cloud），另有 click.mail.zopa.com、cloud.mail.zopa.com、image.mail.zopa.com、view.mail.zopa.com |

## zopa.com 下的常用子域名

www / api / auth / blog / cars / checkout / dash / help / home / payments / sso / rates / merchantsupport / merchantonboarding / mobile-vgs / cdna / openbanking（另有 openbanking-sandbox / openbanking-staging 测试环境）

## 关联品牌：DivideBuy

DivideBuy 是 Zopa 旗下的先买后付品牌，网站写明由 Zopa Bank Limited 拥有和运营。

| 域名 | 用途 |
| --- | --- |
| dividebuy.co.uk | DivideBuy 官网 |
| accounts.dividebuy.co.uk | DivideBuy 账户登录 |
| @dividebuy.co.uk | DivideBuy 邮箱，如 hello@dividebuy.co.uk、customerservice@dividebuy.co.uk |

## 不是 Zopa 的

- FCA 曾发布克隆公司警告：有人冒用 “Zopa Personal Loans (UK) / Direct Zopa UK Money” 等名义行骗，用的邮箱是 outlook.com、gmail.com 等免费邮箱，没有任何官方域名（警告原文见 FCA 官网，2024-01-22 发布，2026-05-13 更新）。
- zopamining.com 等 ZOPA 加密货币项目与 Zopa Bank 无关。
- 只认 zopa.com，其他任何自称 Zopa 的域名都要先核对 FCA 登记信息。
