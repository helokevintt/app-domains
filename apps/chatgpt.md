# ChatGPT (OpenAI) 官方域名

核实日期：2026-11-26
来源：OpenAI 官网及帮助中心、OpenAI 开发者文档、RDAP 注册信息、实测跳转与页面引用

ChatGPT 由 OpenAI 运营。OpenAI 没有公布过完整域名清单，以下是能核实的。

## 官网与主站

| 域名 | 用途 |
| --- | --- |
| chatgpt.com | ChatGPT 官网主站 |
| openai.com | OpenAI 公司官网 |
| chat.com | 2024 年 11 月被 OpenAI 收购，实测 307 跳转到 chatgpt.com |

## 邮件域名

| 域名 | 用途 |
| --- | --- |
| @openai.com | 官方邮件，如客服 support@openai.com（见 status.openai.com 官方页面） |
| c-openai.com | OpenAI 的邮件发送域名，OpenAI 员工在官方论坛确认过其合法性 |

## 其他官方域名

| 域名 | 用途 |
| --- | --- |
| oaistatic.com | ChatGPT 静态资源 CDN，ChatGPT 首页实际引用 persistent.oaistatic.com；OpenAI 帮助中心网络建议中列出 |
| oaiusercontent.com | 用户上传内容与生成文件的托管域名，OpenAI 开发者文档中的文件下载链接为 files.oaiusercontent.com；OpenAI 帮助中心网络建议中列出 |
| sora.com | Sora 视频模型产品站（实测返回 Sora 页面） |
| crixet.com | 原 LaTeX 写作平台 Crixet，OpenAI 收购后改为 Prism；实测 301 跳转到 openai.com/prism/ |
| chatgpt.site | ChatGPT Sites 功能域名，实测 301 跳转到 chatgpt.com/features/sites/ |

## 常用子域名

- openai.com：chat.openai.com（ChatGPT 原地址，现跳转到 chatgpt.com）、platform.openai.com（开发者平台）、auth.openai.com、help.openai.com、developers.openai.com、status.openai.com
- chatgpt.com：ws.chatgpt.com（对话更新，见 OpenAI 帮助中心网络建议）
- oaistatic.com：persistent.oaistatic.com
- oaiusercontent.com：files.oaiusercontent.com

## 不是官方

- ai.com 曾是 OpenAI 的域名（2023 年起跳转到 ChatGPT），但 2026 年 11 月 3 日起改为 xAI 的内容，实测 ai.com/start 已是 xAI 页面，不再属于 OpenAI，不要再把它当作 ChatGPT 入口。
- 登录 ChatGPT 只认 chatgpt.com，OpenAI 官网只认 openai.com；其他任何自称 ChatGPT 的域名都不要登录。

## 未能核实的域名

- openai.org：注册商是 MarkMonitor（与 OpenAI 其他域名同一注册商），历史资料显示 OpenAI 在 2014 年前后获得该域名，但本次核实中该域名没有 live 网站（无法访问），无法确认现状，故不收录。
- yfamilys 规则列表里的大量第三方域名（stripe.com、auth0.com、segment.io、sentry.io、algolia.net、intercom.io、launchdarkly.com、livekit.cloud、datadoghq.com、arkoselabs.com、azureedge.net 等）是 OpenAI 使用的服务商，不是 OpenAI 的域名，已全部排除；oaistatsig.com 同理（Statsig 功能开关服务）。
