## 邮件域名

| 域名 | 用途 |
| --- | --- |
| @x.com | X 官方表示所有邮件只从 @x.com 发出；营销邮件用 e.x.com 子域名 |
| @twitter.com | 历史邮件域名，如 advertiserhelp@twitter.com、twitterflightschool@twitter.com |
| copyright@x.com | X 服务条款中指定的版权代理联系邮箱 |

X 没有客服邮箱，支持请求走 help.x.com 的表单。X 官方表示：邮件绝不带附件，绝不通过邮件、私信索要密码。

## 不是 X 的

- grok.com、x.ai 属于 xAI（独立公司），不是 X 的域名；Grok 在 X 内通过 x.com/i/grok 使用。
- twitpic.com 是第三方图片服务（2008–2014），从未属于 Twitter。
- twitteroauth.com 是独立开源 PHP 库的网站，与 X 无关。
- twitter.map.fastly.net 是 Fastly 的 CDN 主机名，不是 X 的域名。
- 钓鱼域名（SEAL 2025-10 报告点名）：x-arrivals.com、account-updates-x.com、x.copyright.us.com，冒充 X 发 DMCA / 安全提醒邮件，诱导登录或授权恶意应用。
- 只认 x.com / twitter.com；凡是 @x.com 以外发来的所谓 X 安全提醒，都要先在 App 内核实。
