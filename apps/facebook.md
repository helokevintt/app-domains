# Facebook 官方域名

核实日期：2026-11-26
来源：Verisign RDAP（域名服务器记录）、urlscan.io WHOIS（fbcdn.net、facebook.design）、域名跳转实测、Facebook 官方帖子（fb.careers 短链）

Facebook 是 Meta Platforms, Inc. 旗下的社交产品。Meta 没有公布过完整域名清单，以下是能核实的。

## 官网与主站

| 域名 | 用途 |
| --- | --- |
| facebook.com | 官网主站 |
| fb.com | 短域名，跳转到 facebook.com |
| fb.me | 短链接，跳转到 facebook.com |
| fb.watch | 视频短链，跳转到 facebook.com/watch |
| fb.gg | 游戏短链，跳转到 facebook.com/gaming |
| messenger.com | Messenger 网页版 |
| m.me | Messenger 短链接，跳转到 messenger.com |
| fbmessenger.com | 跳转到 messenger.com |
| facebook.net | 基础设施域名 |
| fbcdn.net | CDN，图片/视频内容（如 scontent.xx.fbcdn.net）；WHOIS 注册人为 Meta Platforms, Inc.，域名服务器为 a/b/c/d.ns.facebook.com |
| fbcdn.com | CDN |
| fbsbx.com | 沙箱域名，用于附件/文件预览 |
| facebookmail.com | 通知邮件域名，跳转到 Facebook 帮助页 |
| fburl.com | 短链接服务 |

## 不是 Facebook 的

- Instagram（instagram.com 等）、WhatsApp（whatsapp.com、wa.me）、Oculus/Meta Quest（oculus.com 等）是 Meta 旗下其他产品，不在本文件收录范围。
- meta.com 是 Meta 公司官网，不属于 Facebook 产品。
- fbcdn-a.akamaihd.net 是 Akamai 的第三方 CDN 域名，不属于 Meta。
- 只认上面列出的域名。社区规则列表里大量 facbook.com、faceboook.com、facebooklogin.com 之类的拼写变体未逐一核实归属，不要当作官方域名；凡是索要登录信息或声称中奖的“facebook-xxx”域名，先核对再点。
