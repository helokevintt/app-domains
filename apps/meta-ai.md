# Meta AI 官方域名

核实日期：2026-11-26
来源：Meta 官网及帮助中心、Meta SEC 文件、Meta 官方 GitHub（llama 仓库）、Ars Technica / NY Post 关于 Muse 分享链接的报道、yfamilys MetaAI.list（仅作候选线索，逐一核实）

Meta AI 是 Meta Platforms 的 AI 助手，可在 meta.ai 网页、独立 App 以及 Facebook、Instagram、WhatsApp、Messenger 内使用；Llama 开源模型与 Meta Model API 同属 Meta AI 业务线。Meta 没有公布过完整域名清单，以下是能核实的。

## 官网与主站

| 域名 | 用途 |
| --- | --- |
| meta.ai | Meta AI 助手官网（网页版）；Meta 帮助中心确认“在 meta.ai 使用 Meta AI” |
| ai.meta.com | “AI at Meta”官网，Meta AI 产品、模型与研究 |
| llama.com | Llama 模型官网，现为 Meta Model API 开发者站；Meta 官方博客确认 Llama 模型在 llama.com 提供下载 |

## meta.com 下与 AI 相关的子域名

| 子域名 | 用途 |
| --- | --- |
| ai.meta.com | AI at Meta 官网 |
| developer.meta.com | 开发者文档、Llama 模型下载中心 |
| ai.developer.meta.com | Meta Model API 控制台与文档 |
| aidemos.meta.com | AI 演示 |
| llama.developer.meta.com | Llama 开发者中心 |
| imagine.meta.com | Imagine 图像生成 |

## meta.ai 下的常用子域名

dev.meta.ai（Muse Code 安装脚本，见 llama.com 页面）。

## 其他官方域名

| 域名 | 用途 |
| --- | --- |
| llamameta.net | Llama 模型权重下载；Meta 官方 llama 仓库 README 指明下载链接以 https://download.llamameta.net 开头 |
| metaaiusercontent.com | Muse 分享内容的用户内容域名，分享链接形如 xxx.cf.metaaiusercontent.com（Ars Technica / NY Post 2026 年 10 月报道，Meta 已确认并暂停该分享功能） |
| metaaivm.com | Muse 聊天后端，Muse 会话使用 wss://hatch.metaaivm.com/v1/noise；Meta 官方发布的 Muse 浏览器扩展向 hatch.metaaivm.com 发送数据 |

## 邮件域名

| 域名 | 用途 |
| --- | --- |
| @meta.com | Meta 公司通用邮箱（如 investor@meta.com，见 SEC 文件）；未核实到 Meta AI 专用的发件域名 |

## Meta AI 内置于其他应用

Meta AI 也内置于 Facebook、Instagram、WhatsApp、Messenger，这些应用的域名不在本清单内，另见各自文件。

## 不是 Meta AI 的

- 2026 年 6 月曾出现冒用“Meta AI”名义的垃圾邮件，发件为 metaai944@gmail.com 等免费邮箱，与 Meta 无关。
- Meta 改名后曾出现数万个含“meta”的抢注域名（Crowell & Moring 统计逾 48,000 个），其中不少用于钓鱼；只认上面列出的域名。
- muse.ai 是 Meta 旗下的 Muse 助手，与 Meta AI 助手（meta.ai）是两个不同的应用，不要混淆。
- atmeta.com 是 Meta 投资者关系网站（investor.atmeta.com）的域名，不是 Meta AI 服务。
