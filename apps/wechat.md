# 微信 / WeChat 官方域名

核实日期：2026-11-26
来源：微信官网（wechat.com / weixin.qq.com）、微信公众平台、微信支付官网、DigiCert WHOIS 核验清单（腾讯科技（深圳）有限公司）、WIPO/UDRP 域名裁决、腾讯官方新闻稿

微信是腾讯旗下产品，国内称微信（Weixin），境外称 WeChat。微信没有公布过完整域名清单，以下是能核实的。

## 官网与主站

| 域名 | 用途 |
| --- | --- |
| wechat.com | 国际版官网，另有帮助中心 help.wechat.com、网页版 web.wechat.com |
| weixin.qq.com | 国内官网，公众号、小程序、微信支付的平台入口都在它下面 |
| wx.qq.com | 微信网页版登录入口 |
| weixin.com | 腾讯经 UDRP 裁决从抢注者处取得的域名，现为腾讯所有 |

## weixin.qq.com 下的常用子域名

mp.weixin.qq.com（公众号平台）/ open.weixin.qq.com（开放平台）/ pay.weixin.qq.com（微信支付）/ api.weixin.qq.com（开放 API）/ login.weixin.qq.com（扫码登录）/ channels.weixin.qq.com（视频号）/ dns.weixin.qq.com / weixin110.qq.com（微信安全中心）/ ilinkai.weixin.qq.com（iLink 机器人接入）

注：work.weixin.qq.com（企业微信 WeCom）是独立应用，共用 weixin.qq.com 后缀，不属于微信本身。

## 微信支付

微信支付由财付通支付科技有限公司（Tenpay Payment Technology Co., Ltd.）运营。

| 域名 | 用途 |
| --- | --- |
| pay.weixin.qq.com | 微信支付官网 |
| tenpay.com | 财付通官网，腾讯 2005 年注册 |
| wechatpay.com | 微信支付全球站 |
| wechatpay.cn | 微信支付商户平台，证书持有人为财付通支付科技有限公司 |
| wechatpay.com.hk | 微信支付香港站 |
| wxpayglobal.com | WeChat Pay 新加坡 / Tenpay Global 全球站 |
| tenpayglobal.com | Tenpay Global 跨境支付平台官网 |
| tenpaygo.com | TenPayGo（来华游客独立支付应用，2026 年 9 月上线） |

## 图片 CDN（与 QQ 共用）

腾讯图片 CDN，微信头像、公众号文章图片走以下主机：

| 域名 | 微信侧用途 |
| --- | --- |
| qlogo.cn | 微信头像：wx.qlogo.cn、thirdwx.qlogo.cn、mmbiz.qlogo.cn |
| qpic.cn | 公众号文章图片：mmbiz.qpic.cn |

## 其他官方域名

| 域名 | 用途 |
| --- | --- |
| wechatlegal.net | 微信品牌维权平台 |
| weixinbridge.com | 微信对外跳转桥接域名，公众号文章外链经 mp.weixinbridge.com 跳转 |
| weixinsxy.com | 具体用途未见公开说明；WHOIS 持有人为腾讯科技（深圳）有限公司 |
| wechatos.net | 微信客户端基础设施域名，图片 CDN 的 CNAME 目标（如 mmsns.qpic.wechatos.net） |
| wxapp.tc.qq.com | 小程序文件传输相关主机（腾讯云 CDN，见社区规则列表） |

## 不是微信的

- weixinpay.vip、penpay.com、telpay.ir 等仿冒域名：与微信支付无关，近期钓鱼监测中出现过类似域名。
- wechat.net 曾被抢注，2018 年 WIPO 裁决转给腾讯，不是独立官网。
- 只认上表域名；微信官方不通过邮件索要密码或验证码，客服在 App 内和 help.wechat.com。
